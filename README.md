# 🔥 Пепел Рассвета

Экшен-RPG в духе **The Elder Scrolls** (открытые локации, квесты, NPC, магазины, прокачка)
с боевой системой в духе **Dark Souls** (выносливость, перекаты с неуязвимостью, блок,
фляга эстуса, костры, потеря душ при смерти).

Чистые **HTML + CSS + JavaScript**, без зависимостей и без интернета. Всё в одном архиве.

## Запуск

Просто откройте `index.html` в браузере (Chrome / Firefox / Edge).
Никакой сервер не нужен — игра работает прямо с диска.

> Прогресс сохраняется автоматически в localStorage браузера (у костров, при переходах
> между локациями и каждые 25 секунд). Кнопка «Продолжить» на титульном экране.

## Управление

| Клавиши | Действие |
|---|---|
| WASD / стрелки | Движение |
| Мышь | Направление взгляда / прицел |
| ЛКМ / J | Лёгкий удар |
| ПКМ / K | Тяжёлый удар |
| Пробел | Перекат (неуязвимость в середине переката) |
| C (удерживать) | Блок щитом |
| Q | Захват цели / сброс |
| R | Выпить эстус |
| F | Сотворить заклинание |
| 1–7 | Выбор заклинания |
| X / колесо мыши | Смена оружия |
| E | Говорить / костёр / сундук |
| Tab / I | Меню: инвентарь, персонаж, квесты, карта, управление |
| Esc | Закрыть окно / открыть меню |
| M | Звук вкл/выкл |

## Что есть в игре

- **Сюжет**: солнце угасает — культ Угасания кормит демона Пожирателя похищенными рассветами.
 Основной квест из 4 актов + 4 побочных квеста с наградами.
- **Боевая система (souls-like)**: выносливость на удары/перекаты/блок, телеграфы атак
  врагов (красные дуги), i-frames в перекате, стойка (poise) и оглушение, слом защиты
  (guard break), захват цели, вес снаряжения влияет на скорость переката
  (лёгкий / обычный / неуклюжий).
- **Лечение как в Dark Souls**: фляга эстуса с ограниченным числом глотков, питьё занимает
  время и замедляет; пополнение только у костра. Осколки эстуса увеличивают запас (до 6).
- **Костры**: отдых до утра (полное восстановление, враги восстают), прокачка за души,
  быстрое перемещение между открытыми кострами.
- **Смерть**: души остаются на месте гибели (зелёное пятно) — вернитесь и заберите.
- **Прокачка**: 5 характеристик (живучесть, выносливость, сила, ловкость, интеллект),
  требования и масштабирование оружия.
- **7 типов оружия** с разными мувсетами: прямой меч, кинжал, топор, двуручный меч,
  копьё (длинный узкий выпад), лук (стрелы), посох (усиливает магию).
- **7 заклинаний**: огненный снаряд (взрыв), ледяное копьё (замедление), стрела души
  (самонаведение), исцеление, каменная кожа (броня), огненная волна (AoE), гнев небес
  (молния по захваченной цели).
- **5 локаций**: Тихий Дол (деревня-хаб), Сумрачный лес, Старые руины, Крипта Угасания,
  Пик Рассвета. Запертые двери и врата, ключи и квестовые предметы.
- **NPC и диалоги**: староста, кузнец, чародейка, травница, Лия, стражник, отшельник —
  у каждого свои квесты, товары и реплики, меняющиеся по ходу сюжета.
- **3 магазина**: оружие/доспехи/щиты, гримуары и посохи, еда и кольца. Покупка и продажа.
- **Цикл дня и ночи**: часы в HUD, динамическое освещение (костры, фонари, факелы),
  ночью враги сильнее (+25% урона), но дают +50% душ.
- **Враги**: волки, разбойники, атаман, скелеты, культисты, упыри, призраки +
  **2 босса** с фазами (Костяной Страж призывает скелетов; Пожиратель впадает в ярость).
- **Звук**: синтезируется WebAudio на лету — файлы не нужны.

## Советы новичку

1. Поговорите со старостой Береном (маркер «!») — он запустит сюжет.
2. Красная дуга на земле = враг сейчас ударит. Перекатывайтесь **сквозь** неё.
3. Пейте эстус заранее, а не на последнем HP.
4. Следите за нагрузкой: в латах без выносливости перекат станет неуклюжим.
5. Отдых у костра воскрешает врагов — такова цена света.

## Структура

```
index.html      — каркас и все экраны
css/style.css   — интерфейс в тёмном фэнтези-стиле
js/data.js      — предметы, оружие, магия, враги, квесты, диалоги
js/maps.js      — генерация 5 локаций
js/game.js      — движок: бой, ИИ, рендер, свет, UI, сохранения
```

Приятного странствия, и да хранит вас последний свет. 🕯️
